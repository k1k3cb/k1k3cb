# Communication Style

- Writes in **Spanish** with frequent typos and no diacritics (e.g., "quieor", "me gsuta", "tb me gustaira", "eenfocado", "adema", "tb", "fonrt"). Comfortable mixing Spanish and English tech terms. Confidence: 0.95
- Uses **abbreviations and shorthand** ("tb", "adema", "puedes" → "puede"). Confidence: 0.9
- Gives **references by example** (links to GitHub profiles) when describing a style they like, rather than describing the style abstractly. Confidence: 0.85
- Prefers **interactive confirmations** with multiple-choice options (recommendations clearly marked) before executing significant work like file rewrites. Confidence: 0.7
- Appreciates when the assistant **preserves the parts they explicitly liked** from their previous work, rather than redesigning everything. Confidence: 0.85
- Issues **incremental, itemized change requests** in short messages (one tweak per line, e.g., "añadir X", "eliminar Y", "poner Z", "soluciona lo de X xq no se ve") rather than rewriting whole specs. Confidence: 0.9
- Asks for the assistant's **opinion before deciding** on borderline elements (e.g., "Featured Projects interesante o lo elimino?"), valuing a recommendation but making the final call. Confidence: 0.85
